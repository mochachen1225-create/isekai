# 爬上星之泉（貓貓勇者小隊小遊戲）

改自使用者的《傑克與魔豆》（repo `mochachen1225-create/magicbeans` 1.6 版），玩法不變，主題換成《貓貓勇者小隊》。原本的設計說明和調整過的難度參數請看那個 repo 的 NOTES.md。

## 換了什麼

- 傑克 → 主角（暫時用測驗的 `assets/sprites/player_f.png`，之後換成包包頭＋灰 T 恤的正式點陣圖）
- 拿掃把的媽媽 → 橘貓郵差，要抓她回去睡午覺
- 小鳥 → 烏鴉、巫婆 → 騎掃把的黑貓、綿羊 → 兔子、毛毛蟲／蝸牛 → 史萊姆、蜂窩 → 螢光蘑菇（碰到會看呆 1 秒，第三部的伏筆）
- 巨人的豌豆 → 魔王夢裡踢下來的毛線球；金幣 → 星砂；金蛋 → 星星結晶
- 巨人 → 魔王（灰色大貓、紙板王冠），用肉球摀眼睛玩一二三木頭人
- 角色是點陣圖加白邊，像貼紙貼在瓦楞紙上；背景和道具維持原本的紙板手作風
