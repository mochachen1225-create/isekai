# 爬上星之泉（貓貓勇者小隊小遊戲）

改自使用者的《傑克與魔豆》（repo `mochachen1225-create/magicbeans` 1.6 版），玩法不變，主題換成《貓貓勇者小隊》。原本的設計說明和調整過的難度參數請看那個 repo 的 NOTES.md。

## 換了什麼

- 傑克 → 主角（包包頭、灰 T 恤、赤腳；站、爬、跑、捧星星、看呆五個動作）
- 拿掃把的媽媽 → 橘貓郵差，要抓她回去睡午覺
- 小鳥 → 烏鴉、巫婆 → 騎掃把的黑貓、綿羊 → 兔子、毛毛蟲／蝸牛 → 史萊姆、蜂窩 → 螢光蘑菇（碰到會看呆 1 秒，第三部的伏筆）
- 巨人的豌豆 → 魔王夢裡踢下來的毛線球；金幣 → 星砂；金蛋 → 星星結晶
- 巨人 → 魔王：灰藍白賓士貓，個性最中二、最屁（像貓界的哈士奇）。下巴有一撮深色毛。唸口訣時用肉球摀眼睛、不動；轉頭時睜大黃眼睛盯著妳、輕輕上下浮。身體藏在城堡後面的霧裡
- 城堡：點陣風（`img/castle.png`，Python 一格一格畫的，程式在 `isekai-studio` 的 `work/sprites/castle2.py`），中間主堡＋兩座塔＋左右城牆。下面的雲海和石板路也是點陣風（`pixelBank()`）
- 「一二三木頭人」改成沒有框的大字，放在城堡下面，不遮臉
- 藤蔓 → 三根麻繩柱（貓跳台）：直的、點陣風，柱子上有懸空的平台、貓窩、吊床、逗貓棒（只是裝飾，不影響玩法）。種子長出來的是貓跳台，底下有一塊底座。斷藤 → 柱子斷一段、麻繩散開。玩法和難度沒變（柱子不再左右晃，位置差幾像素）
- 地面全部改成點陣風：草地、土、遠山、小村子、雲、太陽。紅色穀倉 → 橘貓的樹屋（大樹、橘色屋頂小木屋、梯子、樹下貓門、郵差信箱，橘貓從貓門衝出來）。右邊是白柵欄、毛線球籃子、「橘貓的家」牌子（牌子上是橘貓頭）
- 點陣畫法都在 `index.html` 裡：`pix()` 在 1/3 大小的小畫布一格一格畫再放大；柱子是 `paintStalk()`；改版用的修補程式在 `isekai-studio` 的 `work/sprites/patch_posts.py`
- 文字裡的「藤」都改成柱子／貓跳台
- 熱氣球 → 送貨的鵜鶘，跳過去抓住木箱就會被載上去
- 天空背景改成手帳方格紙（左邊紅色邊線、紙膠帶）
- 角色是點陣圖加白邊，像貼紙貼在瓦楞紙上；地面和道具維持原本的紙板手作風
- 新角色圖在 `img/`：2026-10-28 用 Gemini 畫一張 4×4 角色表（約 NT$2.2），程式裁切、去背、縮到約 96px 高。原始角色表在 `isekai-studio` 的 `work/sprites/`

## 配樂（2026-10-28）

- 兩首都是使用者用 Gemini 做的：主關卡 `audio/cb.m4a`（Cloudbound Postman），魔王關 `audio/tt.m4a`（Tuxedo Tyrant's Standoff）。原檔在 `isekai-studio` 的 `uploads/music/`
- 用頻譜相似度找循環點（主關卡 20.3→52.3 秒、魔王關 14.3→51.3 秒），接縫交叉淡化 0.25 秒；檔案前後各多 0.5 秒，播放時用 `loopStart`/`loopEnd` 跳過，所以不會有 AAC 開頭空白造成的斷點
- 開始遊戲淡入 1.5 秒，換關卡交叉淡化，失敗時淡出；切到別的分頁會暫停。靜音按鈕原本就有（記在 localStorage `jack_mute`），現在也管配樂
